Tick tables. Tick templates.
Get code.

A source-code generator that reads the metadata of any database with a JDBC driver and renders it through templates — one file per table and template.

Free and open source (MIT) · Windows, macOS and Linux

Features

Your schema in, your boilerplate out.

Models, mappers, DAOs — whatever your templates describe, for as many tables as you tick.

Pick what to generate

A checkbox on every table, remembered per connection, and an inspector for keys, foreign keys and indexes.

jdbgen templates, unchanged

The same placeholders, conditions, loops and decorators as jdbgen, so its templates render here as they are.

Template editor

Highlighting, completion of the model's fields and a live preview against a real table as you type.

Preview and dry run

Render one pair into a tab, or list every file a run would write. Runs are cancellable and writes atomic.

Any JDBC driver

From Maven Central or disk, each in its own class loader, with custom metadata queries when a driver gets it wrong.

Tunnels, no master password

SSH through a bastion with agent, password or key. Secrets live in the OS keychain, or are asked on connect.

Install

Up and running in a minute.

Every download carries its own Java runtime and a sample H2 database, so there is something to connect to right away.

Installer or portable zipThe -setup.exe installs for the current user, with no administrator rights.

Latest release

Windows 10 and 11, x64 and ARM64. If SmartScreen objects, choose More info → Run anyway.

$ brew install --cask xcomart/tap/rudbgen

Apple Silicon and Intel. The cask clears the quarantine flag, so the first launch just opens.

# the x86_64 or aarch64 linux-gnu archive from the latest release
$ tar xzf rudbgen-v*-x86_64-unknown-linux-gnu.tar.gz
$ cd rudbgen-v*/ && ./install.sh

Installs under ~/.local with no root. Needs glibc 2.35 or newer — Ubuntu 22.04, Debian 12 and later. Or run the AppImage from the same release, with nothing to install.
